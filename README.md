# dsh-task-status-window

把 DeepSeek Harness 工作区里的任务状态放进一个**系统级置顶窗口**，让你在切到别的应用时也能实时看到任务进展，并一键回到对应任务。

> ## ⚠️ 只支持 DeepSeek Harness **桌面版（Desktop）**
>
> 这个插件要的是**操作系统级的浮窗**，而且要求它能**置顶**在所有窗体最前面。
> 这依赖桌面外壳，因此：
>
> - ✅ **DeepSeek Harness Desktop（Windows / macOS）**：完全可用。
> - ❌ **dsh web 版本**：**不提供支持**。web 版没有桌面外壳可依附，插件会照常出现在插件列表里，但宿主日志里会写明「当前运行环境没有桌面外壳」，并且不会拉起任何窗口。
>
> 这不是一个可以打开的开关，而是实现方式决定的：浮窗由插件自带的原生进程绘制，Web 版本的浏览器页面无法承载系统级置顶窗口。
>
> 需要 Python 3（带 Tk）。DeepSeek Harness 自带的运行时里已经有一份；找不到时可以用环境变量 `DSH_PYTHON` 指定解释器。

---

## 它解决什么

DeepSeek Harness 的工作区侧栏已经用三种状态提示标出需要关注的任务：

- **加载动画** —— 任务正在跑；
- **黄点** —— 任务在等你批准 / 回答 / 审计划；
- **绿点** —— 任务跑完了，等你确认。

但这些提示只存在于 DeepSeek Harness 自己的窗口里。一旦你切到别的应用，就看不见它们了 —— 任务在后台卡住、或者跑完了你不知道，都会变成「等回来看一眼才发现」的事。

这个插件把这些状态搬到一个**始终置顶的小窗**里：它浮在所有窗体最前面，你在任何应用上都能看到「有没有任务在等我」。

![浮窗的三种任务状态](docs/images/panel-states.png)

<sub>展开状态：运行中转圈、待批准黄点、办结待确认绿点；行尾写「待审批 / 计划待审 / 待回答」或相对时间。</sub>

收起列表后只剩一条标题栏，标题旁按状态显示图标：

![收起的浮窗](docs/images/panel-collapsed.png)

<sub>收起时标题右侧依次是转圈、黄点、绿点，右边三个按钮依次是收起、置顶、关闭。</sub>

## 功能

- **三种状态一屏可见**：运行中、等待处理、办结待确认。
- **顶部栏一目了然**：右端三个按钮 —— 收起/展开任务列表、置顶/取消置顶（图钉，用的是界面同一枚图标）、关闭浮窗（关闭后可在插件管理页里重新打开）。把列表收起后，标题旁会按任务状态显示图标（运行中转圈、待处理黄点、已完绿点），列表展开时就不重复显示。
- **点击即回主界面**：点一行，DeepSeek Harness 的主窗口会被拉到前面并切到那个任务页面。任务是在**主体程序（桌面版窗口）里**打开的，不是只在某个浏览器标签页里；窗口原本是最大化的就保持最大化，不会因为这一次点击缩回初始大小。
- **任务行与主界面同一套**：每行是「状态点 + 标题 + 行尾计时」，行高 32 像素、标题 14 像素、计时 10 像素，字号与配色都取自主界面工作区的会话题目行。
- **行尾那一格**：等待用户处理的任务写「待审批 / 计划待审 / 待回答」，其余写任务进入当前状态之后过了多久（刚刚 / N分钟 / N小时 / N天）—— 规则与主界面工作区题目行末尾那一格一致。
- **状态与侧栏一致**：浏览器半侧把侧栏用的会话状态（运行中 / 等待用户处理 / 办结未读）定期回传给宿主，浮窗照搬它，因此黄点、绿点与侧栏完全对得上，包括插件启动前就已经在等待的审批。
- **绿点会跟着主界面走**：在主界面里把已完成的任务读掉之后，侧栏的绿点消失，浮窗上的绿点也在几秒内一起消失。
- **标题放不下会滚动**：平时缩略成省略号，鼠标停在上面时按主界面的速度把整条标题走马灯式滚出来，滚到头停住。
- **高度跟着任务多少走**：一个任务一行，浮窗随之变高变矮；没有任务时也留一行高度并显示提示。**宽度**可以拖右下角调整，高度始终由任务数量决定。
- **真圆角**：窗口四角被抠成透明，浮窗外面不会露出一圈深色的直角框；收起时顶部栏下边缘也跟着变成圆角。
- **图标与主界面同一套**：状态点是 10 像素方框里的 6 像素圆点，加载图标是 14 像素的圆环（淡色轨道 + 会呼吸的圆弧），尺寸与画法都照搬界面里的实现。
- **自由摆放**：拖标题栏移动，浮窗被限制在虚拟屏幕内，不会被拖到找不回来的地方。
- **记住尺寸**：调整后的宽度与位置会写回插件配置，**关掉 DeepSeek Harness 再启动，浮窗以同样的尺寸出现**。
- **数值设置**：在插件管理页里用数值直接控制浮窗宽度、初始位置与刷新间隔，超范围时输入框会直接提示，避免误操作把窗口缩到找不回来。页面底部还有「放弃改动」与「恢复默认」。
- **跟随主题**：底色、文字色与三个状态色都取自界面使用的 `--dsw-alias-*` 主题 token（状态色映射与界面里的状态点一致），字体取自 `--dsw-font-family`，文案跟随界面语言；深浅色主题都会同步。

## 安装

直接从 GitHub 装：

```bash
dsh plugin install https://github.com/Lroyia/dsh-task-status-window.git
```

或者克隆下来再装本地目录：

```bash
git clone https://github.com/Lroyia/dsh-task-status-window.git
dsh plugin install ./dsh-task-status-window
```

也可以在 DeepSeek Harness 里打开 **插件 → 添加插件**，选择本地目录 `dsh-task-status-window`。

安装后重启 DeepSeek Harness Desktop，浮窗会出现在屏幕右下角。

## 架构

```
┌──────────────────────── DeepSeek Harness Desktop (Electron) ────────────────────────┐
│                                                                                       │
│  ┌────────────┐   宿主路由族    ┌──────────────────────┐        ┌───────────────────┐  │
│  │ Host half  │◄───────────────►│ 浏览器 half（页面内）│        │ native/panel.py  │  │
│  │ index.js   │  /api/dsh-task- │ client.js            │        │ （Python + Tk）  │  │
│  │            │  status-window/ │  · 插件管理页的数值设置│        │ 真正的置顶窗口    │  │
│  │ 任务状态派生│                 │  · 回传主题 token     │        │ 拖动 / 缩放 / 点击│  │
│  │ 浮窗进程看护│                 │  · 领取聚焦请求       │        └─────────┬─────────┘  │
│  └────────────┘                 └──────────────────────┘                  │           │
└───────────────────────────────────────────────────────────────────────────┼───────────┘
                                                                    loopback HTTP + 令牌
```
- **Host half（`index.js`）** —— 从运行时的真实事实派生任务清单（Agent 运行状态、审批与提问的等待、刚跑完的会话），在宿主 web server 上注册插件自己的路由族，并拉起 / 看护浮窗进程。
- **浏览器 half（`client.js`）** —— 在插件管理页提供数值设置，把当前主题 token 与文案回传宿主，并领取浮窗发来的「切到某个任务」请求。
- **浮窗进程（`native/panel.py`）** —— 一个独立进程，用 Tk 画出无边框置顶窗口；只依赖 Python 标准库。宿主退出时它会跟着退出。

## 路由族

| 路径 | 用途 | 访问方 |
|---|---|---|
| `GET /api/dsh-task-status-window/state` | 任务清单、主题、窗口几何 | 浮窗进程（带令牌） |
| `POST /api/dsh-task-status-window/geometry` | 回报窗口宽度与位置 | 浮窗进程（带令牌） |
| `POST /api/dsh-task-status-window/focus` | 请求切到某个任务 | 浮窗进程（带令牌） |
| `POST /api/dsh-task-status-window/topmost` | 置顶 / 取消置顶 | 浮窗进程（带令牌） |
| `POST /api/dsh-task-status-window/close` | 关闭浮窗 | 浮窗进程（带令牌） |
| `POST /api/dsh-task-status-window/theme` | 回传主题 token 与文案 | 浏览器半侧（宿主信任栅栏） |
| `POST /api/dsh-task-status-window/statuses` | 回传会话状态（侧栏同款） | 浏览器半侧（宿主信任栅栏） |
| `POST /api/dsh-task-status-window/focus-claim` | 领取一次聚焦请求 | 浏览器半侧（宿主信任栅栏） |

浮窗进程使用的路由要求请求来自回环地址并带上本次启动随机生成的令牌；浏览器半侧使用的路由交给宿主自带的信任栅栏（`connection.requestRejection`）把关：只有 DeepSeek Harness 自己的页面能过，本机上的其它页面一律拒绝。桌面版窗口的请求由桌面外壳转发给宿主，转发时会被去掉浏览器的 `Origin` 标记，因此这一侧靠宿主签发的会话 cookie 认人 —— 桌面版与浏览器标签页都能正常调用。

「切到某个任务」的请求只交给**桌面版窗口**领取（浏览器标签页不抢）：只有它才是用户眼前那个主体程序，任务要在那里打开。桌面版窗口不在场时（例如只用 web 版）才轮到浏览器标签页；请求超过 15 秒没人领就作废，不会过很久突然跳到某个任务上去。

## 已知边界

- 点浮窗里的任务时，任务是在**桌面版窗口**里打开的。如果桌面版窗口已经关掉、只有浏览器标签页开着，请求就由浏览器标签页领取，任务会在那个标签页里打开。
- 「办结待确认」的绿点跟着主界面走：在主界面里把这个任务读掉之后，侧栏的绿点消失，浮窗上的绿点也在几秒内一起消失（从浮窗里点开同样会消）。
- 浮窗需要 Python 3 与 Tk。找不到解释器时插件会在宿主日志里给出提示，其它能力不受影响。
- 浮窗进程退出后会自动重新拉起；如果你想彻底关掉浮窗，请在插件管理页里关掉「显示浮窗」开关，或停用这个插件。
- 浮窗高度由任务数量决定；任务多到超过屏幕高度时封顶，超出的部分靠滚轮查看。
- 任务列表的滚动靠鼠标滚轮，没有键盘导航。
- 行尾计时在插件（浮窗进程）重启后会从「刚刚」重新开始 —— 这段时间存在宿主的内存里，没有写盘。
